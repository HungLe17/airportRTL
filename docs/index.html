Realtek RTL8852BE Wi‑Fi and AirDrop on macOS Tahoe

airportRTL pairs a Realtek rtw89 PCIe Wi‑Fi driver with a USB Bluetooth kext for Intel-compatible x86_64 Hackintosh systems running macOS Tahoe 26.7.1.

Download the latest release OpenCore installation Source code

What was tested?

The published baseline is RTL8852BE (PCI 10ec:b852, USB Bluetooth 13d3:3571) with OpenCore 1.0.8 and macOS Tahoe 26.7.1. Two-way AirDrop with an iPhone 8 Plus was demonstrated on v0.1.1. The project also reports working Wi‑Fi, Bluetooth LE, AirPods, Handoff and Universal Clipboard on the baseline.

Personal Hotspot and iPhone Mirroring failed on the recorded setup. Sleep/wake is untested. Older macOS versions and USB Wi‑Fi adapters are not supported by the current release. A separate Bluetooth failure report concerns a different USB ID on Tahoe 26.7.3 with a manually modified kext.

Which other Realtek cards can I test?

v0.1.2 adds or includes PCIe matches for RTL8851BE, RTL8852AE, RTL8852BE, RTL8852BTE, RTL8852CE, RTL8922AE and RTL8922DE. Matching a PCI ID does not establish that Wi‑Fi, Bluetooth or AirDrop works on that card.
